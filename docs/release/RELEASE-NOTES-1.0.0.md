# OpenLearn 1.0.0 release scope

The repository is ready as a portable 1.0.0 baseline when the
[stable release checklist](STABLE-RELEASE-CHECKLIST.md) is approved by the
deployment owners.

The release scope is the validated learning-plan domain, authenticated
dashboard/service boundary, external-client MCP integration, server-side
progress and deletion semantics, provider-neutral identity, PostgreSQL
persistence, recovery/retention operations, connected dashboard build, and
the documented beta feedback/support process.

1.0.0 does not claim a built-in AI provider, anonymous production share links,
implicit account linking, a specific cloud vendor, or a jurisdiction-specific
legal certification. Those boundaries are intentional and are part of the
release communication.
